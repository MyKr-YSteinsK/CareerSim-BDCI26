# 历史对局策略模式手册 | Historical Strategy Playbook

**Status / 状态:** 离线证据整理；仅用于形成下一轮待验证策略，不构成已验证最优策略。
**Scope / 范围:** S01、S03-14、SCORE-01、S04-03 四条历史轨迹。没有运行游戏、读取隐藏状态或访问 S04-04。

## 证据标签 | Evidence labels

- **FACT / 事实:** 可从哈希核验的原始公开 observe、工具调用/结果或已提交 score report 直接复核。
- **INFERENCE / 推断:** 对多个直接观察的保守解释；仍可能受事件序列、阶段和存活时长混杂。
- **HYPOTHESIS / 假设:** 候选机制，必须由后续受控实验检验。
- **UNKNOWN / 未知:** 当前证据无法回答；不补写阈值、原因或效果。

这里的 confidence 代表字段来源的可复核程度，不代表因果置信度。情节类事件族按确定性标题关键词规则生成，误分类可能性较高；除精确系统/季度标题外均按低置信度阅读。

## 可复用观察 | Reusable observations

### 1. 季度主行动保持稳定

- **FACT:** 四局均观察到“申请关键项目”作为季度主行动：S01 为 6/6，S03-14 为 2/2，SCORE-01 为 7/7，S04-03 为 16/16。该选项在公开菜单中的状态变化为 Output +2、Skill +1、Network +1，Energy cost 为 0。
- **INFERENCE:** 这是一条反复采用的公开收益路径；SCORE-01 和 S04-03 的结果差异说明，单凭重复该动作不足以解释整局分数。
- **边界:** 不能据此称它为全局最优，也没有证据支持强制更换主行动会提高成绩。遇到当前菜单或公开规则变化时，应重新读取并比较。

### 2. 能量分配随公开状态调整，但效果未隔离

- **FACT:** S04-03 共记录 48 个 Energy points：汇报材料 25、人脉维护 6、健康恢复 11、处理历史埋雷 3 次（每次成本 2）。其三个 rolling-planning 检查点提到了能力/可见产出、人脉/产出缺口和健康缓冲，并分别提出后续资源取舍。
- **FACT:** SCORE-01 共记录 21 个 Energy points：汇报材料 10、人脉维护 6、健康恢复 3、处理历史埋雷 1 次（成本 2）。在 Month18 低健康时，该局选择了两次健康恢复；Month21 网络值为 3 时选择了两次人脉维护。该适应行为发生时没有 rolling-planning Skill。
- **INFERENCE:** 观察当前公开缺口后调整资源分配，值得保留为决策习惯；现有材料不能把这种调整归因于 rolling-planning，也不能证明增加恢复次数导致更长存活或更高分。
- **边界:** 不从这些小样本推导健康、网络、产出或晋升阈值。按当前公开状态和可见菜单记录取舍。

### 3. 同标题情境不能直接复用固定答案

- **FACT:** SCORE-01 与 S04-03 有 49 个相同精确标题/出现序号的观察情境；6 个情境选择不同。采用更严格条件（相同六个月阶段、相同 level，并且 health ≤2、skill ≤5、network ≤3、output ≤3、dignity ≤2）后，没有一个不同选择情境可比。
- **INFERENCE:** 事件标题相同并不能证明处于同一链阶段、同一状态或同一选择后果。on-call 事件的两个实例在月份、level 和健康状态上不同，不足以给出一条固定答案。
- **操作建议:** 保存精确标题、出现序号、月份、公开状态和选项；只有关键状态与阶段也接近时，才把历史选择作为弱参考。未匹配时保持 UNKNOWN。

### 4. Risk 标记不是效果证明

- **FACT:** S03-14、SCORE-01、S04-03 共出现 ALLOW 37、WARN 33、RECONSIDER 2 个 Risk 标记。SCORE-01 与 S04-03 的 risk_control 原始值都为 0、归一化分都为 100。
- **INFERENCE:** 当前轨迹不支持“Risk Review 过于保守”的结论，也不能证明它改善了风险或分数。归一化分数相同不能替代动作级对照。
- **操作建议:** 把标记对应到具体候选动作、最终选择和随后公开结果；单独报告拦截、放行和后果，不以标记数直接评价策略。

### 5. Structured State Board 的持续使用未证明

- **FACT:** S04-03 中 Skill 被加载；已核验的 transcript 有一次初始 board-like 输出，包含 observed / inferred / unknown 类别，随后初始计划优先考虑 Skill、Network、Output。输出没有显式 `game_session_id` 字段；后续刷新和每次动作后的新鲜 observe 不能由现有记录证明。
- **UNKNOWN:** 跨动作持续使用、会话隔离、压缩恢复以及分数贡献均未知。
- **操作建议:** 后续若获准验证，记录 game session、observe 序号/时间、来源新鲜度和刷新触发点；不要把一次初始输出记成持续状态收益。

## 结果读取 | Reading the outcomes

S01 得分 26.95、存活 19 个月、E；SCORE-01 得分 33.06、存活 24 个月、D；S04-03 得分 76.04、存活 48 个月、A。S04-03 相对 SCORE-01 的 +42.98 分和 +24 个月是**方向性单局差异**。仅三个已评分局、随机事件路径不同、Skill 组合不同，不能推导 Skill 的因果贡献。S03-14 在 Month9 结束且没有终局分数，是风险正确性早期运行记录，不作分数基准。

S01 被归类为“未指定专门策略的基线”，其 77 条动作调用仍包含实际模型选择；不能将该标签误读为模型全程 no-op。所有对局的精确终止原因均为 UNKNOWN。

## 不应编码为策略规则 | Not supported as rules

- 固定事件标题对应固定选项。
- 隐藏的晋升、淘汰、健康或资源阈值。
- “rolling-planning 提升了 X 分”“Risk Review 降低了淘汰率”等因果数字。
- 根据 risk_control 归一化值判定 Skill 有效。
- 声称 state board 已持续跨动作维护或提升分数。
- 把工具调用成功计数当成有效游戏动作数；SCORE-01 有一次无效 JSON 在派发前被拒绝，修正后另一次调用成功。

## 下一步策略检验 | Next experiment

建议在 Main 批准下一阶段后，仅隔离测试 rolling-planning 的边际价值：让两组保持 Action Trace、Risk Review、Structured State Board、主行动规则及其他配置一致，只切换 rolling-planning；若官方运行合同支持固定种子则按相同种子配对，否则做多次独立重复并如实报告波动。比较 Month6/12/18/24 的新鲜公开状态、能量分配、规划建议到实际选择的对应关系及终局分数。此处是候选实验设计，不是当前授权的运行指令；PAR-01 没有启动实验。
