# S04-03 高分归因｜离线、非因果

## 结论

从 SCORE-01 到 Candidate Run #1 的提升应归类为 **C｜策略与环境/轨迹混合，因果贡献未知**，而不是“rolling-planning 带来高分”。观察到策略行为差异，也观察到显著不同的叙事事件轨迹；现有两份历史记录不能识别各自对分数的贡献。

## A｜策略相关的可观察行为

- SCORE-01 与 Candidate Run #1 的前 7 个季度主行动均为 `申请关键项目`（7/7 相同），所以主行动改变不能解释跃迁。
- 前 7 个季度的能量行动中，两局 `准备汇报材料` 都出现 10 次；Candidate Run #1 选择 `健康恢复` 7 次、`人脉维护` 4 次、历史埋雷清理 0 次；SCORE-01 分别为 3、6 和 1 次。该计数是 action selection 次数，不代表消耗的 Energy 点数。
- Run #1 的 raw/transcript 记录了 3 个 rolling-planning checkpoint。可见调整包括在 Health 下降时安排恢复，并在公开 C 级反馈要求更清晰 Output 后优先恢复 Health、增加可见产出。上述是策略过程证据，不证明其导致晋升、存活或分数增长。
- 归类：**A（行为差异存在）— 置信度高；对分数提升的因果贡献 — 置信度低，未估计。**
- 可证伪/更新条件：Run #2 若未复现这些选择或反馈响应，将削弱“该行为是 Candidate 稳定特征”的判断；若行为复现但结果仍明显分化，则不能单凭行为复现主张其带来稳定高分。

## B｜环境 / 机会轨迹差异

- 1–24 月精确匹配的“月份 + 叙事事件标题”仅 6 项；Candidate Run #1 有 67 个唯一月份-事件项，SCORE-01 有 63 项，分别有 61 和 57 项未匹配。可见两局经历的叙事机会轨迹显著不同。
- 事件差异可能来自随机性、先前行动引发的路径变化或两者交互；现有证据无法区分。晋升时点、review 与事件收益/惩罚的因果拆分也未知。
- 归类：**B（轨迹不同这一描述性事实）— 置信度高；其对分数差的贡献大小及来源 — UNKNOWN。**
- 可证伪/更新条件：若源事件表与 transcript 的独立复核发现月份-事件匹配统计错误，应重算该描述性结论；即便复核通过，也不能据此把事件差异直接等同于 RNG。

## C｜整体分数跃迁：混合 / 歧义

| 指标 | SCORE-01 | Candidate Run #1 | 差值 |
|---|---:|---:|---:|
| Quantitative score | 33.06 | 76.04 | +42.98 |
| Competition partial score | 23.14 | 53.23 | +30.09 |
| Survival | 24 个月 | 48 个月 | +24 个月 |
| Grade | D | A | — |

Run #1 的长期存活、技能和财富结果与其策略调整及不同晋升/叙事轨迹同时出现。没有足够反事实或重复样本分配 42.98 分给任一因素。`risk-review` 的加载或游戏总分都不是 Risk 策略有效性的证据。

- 最可能分类：**C｜Mixed / ambiguous**。
- 对“行为和机会轨迹都不同”的判断：**置信度中**（单次 Candidate 与一个历史对照）。
- 对具体因果贡献及可重复性的判断：**置信度低 / UNKNOWN**。
- 更新/证伪条件：Run #2 若保持相近行为但得分与存活接近 SCORE-01，将否定“Run #1 的策略路径已显示稳定高分信号”；若在不同事件轨迹下仍复现明显优势，会增强而非证明策略贡献的解释。一次确认局不能建立统计显著性或因果分解。
