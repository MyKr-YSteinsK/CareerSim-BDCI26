# S05-02 benchmark observation contract — future run only

This matrix is frozen **before** any next benchmark. It is not authorization to install, start a service, call a provider, or play. A future Main-authorized task must verify the actual candidate Skill blobs, record its fresh game/drive IDs, and use that run's timestamped public `observe`/legal-option/action evidence. Score reports and terminal summaries are for **post-run offline analysis only**, never decision-time Skill input.

Status rule for each question: `PASS` = a qualifying opportunity occurred and the specified observable contract behavior is evidenced; `FAIL` = a qualifying opportunity occurred and evidence shows a contract violation; `NOT_OBSERVED` = no qualifying trigger/opportunity occurred or the game ended before the checkpoint; `UNKNOWN` = trigger or behavior cannot be established from retained evidence. `NOT_OBSERVED` and `UNKNOWN` must not be silently converted to `FAIL` or `PASS`. A one-run PASS is execution evidence, not causal benefit.

| Question | Future evidence source and measurement definition | PASS / FAIL / NOT_OBSERVED / UNKNOWN application |
|---|---|---|
| Material reprioritization trigger | Public event/feedback + fresh `observe` at trigger month; previous and next Planning checkpoints, old/new `Priority`, legal path comparison. | PASS if old goal is reopened and legal alternatives/trade-offs considered; FAIL if severe public trigger appears and old goal is carried unchanged without comparison; NOT_OBSERVED if no trigger; UNKNOWN if checkpoint provenance missing. |
| Composite-benefit comparison | Quarterly public state/gaps, legal Energy menu and costs, bounded Planning `Path trade-off`, chosen actions. Record each discussed benefit component and opportunity cost. | PASS if useful components and cost are compared; FAIL if one saturated component nullifies all benefits or multi-benefit automatically wins; NOT_OBSERVED if no qualifying composite choice; UNKNOWN if menu/checkpoint unavailable. |
| M6 trajectory | Last fresh M6 `observe`: Level, Wealth, Skill, Network, Output, Health; quarter Energy/main actions and feedback. | PASS if source/time and all six fields captured; FAIL if a present source is misreported; NOT_OBSERVED if game ends earlier; UNKNOWN if evidence missing. |
| M12 trajectory | Same six fields and action/feedback identity from last M12 `observe`. | Same milestone rule; compare with S04 anchors only **after** capture, without causal attribution. |
| M18 trajectory | Same six fields, first-L4/promotion state, quarter actions and feedback from last M18 `observe`. | Same milestone rule; no imputation if unreached. |
| M24 trajectory | Same six fields, promotion state, quarter actions and feedback from last M24 `observe`; derive S04 divergence only offline. | Same milestone rule; a later terminal result cannot be used to explain M24 choice correctness. |
| Severe-outcome objective response | Consequence timestamp and public basis, immediately prior/next `Priority`, legal path alternatives and chosen action. | PASS if objective change/reaffirmation is evidence-based after comparison; FAIL for unexamined carry-over; NOT_OBSERVED if no severe outcome; UNKNOWN if no traceable before/after. |
| Normal growth false positives | For legal growth opportunities with no material risk, count cases where material checkpoint or Risk review was invoked solely to force conservative choice; retain representative public input/checkpoint. | PASS if qualifying cases have zero such false positives; FAIL if any is evidenced; NOT_OBSERVED if no qualifying growth opportunity; UNKNOWN if trigger classification unclear. No blanket growth-first mandate. |
| Board/Planning/Risk separation | Representative Board fact/freshness snippets, Planning checkpoint and Risk state for the same decision; classify copied-state, objective ownership and candidate-risk ownership. | PASS if Board remains facts, Planning objective/trade-off, Risk candidate-specific; FAIL if duplicated full Board, Risk rewrites goal or Board recommends an action; NOT_OBSERVED if a role is never invoked; UNKNOWN if transcript missing. |
| Plateau reconsideration | Previous objective/checkpoint, repeated strategic behavior, fresh public progression/non-progression, current legal alternatives, progress label and response. | PASS if stalled objective prompts legal alternative/cost comparison while advancing objective may continue; FAIL if stalled repeats without review or advancing forces a switch; NOT_OBSERVED if no repeated strategy or no comparable interval; UNKNOWN if prior checkpoint absent. |
| Final headroom | Post-game score report dimensions plus final public trajectory; offline compute Level/Wealth/Skill/Network/Risk/Resilience headroom and Output context. | PASS if all available dimensions reconciled to report; FAIL on arithmetic/provenance mismatch; NOT_OBSERVED if no completed report; UNKNOWN on missing/ambiguous fields. No score weight enters Skills. |
| Reasoning drift | Timestamped transcript/checkpoints: bounded count/examples of repeated full-state restatement, marker re-review, and unbounded deliberation; correlate with token/runtime records where available. | PASS if observed checkpoint remains bounded and no repeated re-review pattern; FAIL if clear repetitive loop violates bounded contract; NOT_OBSERVED if relevant checkpoint never occurs; UNKNOWN if transcript unavailable. No arbitrary token threshold is invented. |
| Action authority | Events/tool calls by drive/game ID and Skill outputs; count Skill-direct action submissions and successful `take_action` by the sole Agent. | PASS if exactly one Agent submits and Skill-direct submissions = 0; FAIL if another action submitter appears; NOT_OBSERVED if no game/action; UNKNOWN if call attribution incomplete. |
| Cost / runtime | Runner/provider usage record, by-model tokens/cache/cost if reported, wall-clock and service lifecycle. | PASS if obtainable usage is recorded with source and unavailable fields marked; FAIL if reported values are misrepresented (e.g. zero cost inferred from missing data); NOT_OBSERVED if no live run; UNKNOWN when provider accounting is absent. |
| Failure classification | Runner exit, game session, score/terminal report, events and service logs. Distinguish elimination, technical failure, timeout and unknown side effect. | PASS if classified from evidence; FAIL for unsupported success/strategy claim or blind retry; NOT_OBSERVED if no failure; UNKNOWN if outcome cannot be resolved. |

A single expensive game can check whether mechanisms **ran** on its observed path and whether they were visibly misapplied. It cannot prove stable 80+, reduce variance, isolate the integrated patch's causal score effect, estimate tail risk, or generalize to hidden Test. Absence of a severe event, plateau or composite choice is `NOT_OBSERVED`, not mechanism failure. The next Game Gate remains a separate Main decision.
