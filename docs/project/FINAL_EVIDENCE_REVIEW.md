## Interpretation rules

- **FACT** 只记录关联来源中直接报告的身份、数值、事件和状态；**INFERENCE** 仅作有限的跨记录解释；缺失或未复核的信息写 `UNKNOWN`。
- 单局只描述该 run。不同 Candidate、随机轨迹或不完整来源之间不构成因果对照；少量样本的范围、均值、完成率均为描述统计，不是性能分布或稳定性证明。
- `quantitative`、`competition partial`、survival、grade、Level 和 promotions 按记录分别列出。未到终局的技术失败不补造终局分数或 grade。
- Display ID 是导航编号，不取代 Stage / Task / Candidate / Run 身份。来源 commit 与记录 commit 分开列；raw 的 hash 不能替代 raw，也不能关闭 hold。
