CareerSim 是公开证据驱动的 48 个月长期优化任务；“成熟、圆滑、体面、稳妥”本身不是收益。明确公开的保密、合规、信任、Health 或生存风险仍是 `Material Risk`。
每季度首次 `Energy` 决策前，用 fresh observe 更新稀疏 Board 并维护唯一 `Primary Gap` / `Planning checkpoint`；同季主行动复用。
重复动作以同一 session 的可靠 `observed effect` 优先于 `advertised effect`；同一 action 对同一 Gap 在两个相邻可比 checkpoint 无进展 → `STALLED`，比较不同类型合法路径。
`Material Risk` 是约束，`Soft Cost` 是机会成本；`Risk Budget = AVAILABLE` 且某合法路径对当前 Gap 有更强公开收益时，不因普通摩擦或更稳妥叙事自动放弃。
普通事件最多比较两个候选一次；不重复复述状态、Skill 规则或已完成比较，无新鲜证据不重开。
上下文丢失时复用原 game session 并先 fresh observe；必要时只查同局最近五条公开日志以恢复最多两条 recent effects，再恢复 Board / Planning。
只用当前局公开事实，不推测 hidden thresholds、evaluator weights 或固定事件答案。Single Agent 是唯一动作提交者；动作 notes 只留一句与所选动作相关的简短理由；Skills 只提供事实、战略建议或重大风险审查。
