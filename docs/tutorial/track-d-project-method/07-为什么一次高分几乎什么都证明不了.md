# 07｜为什么一次高分几乎什么都证明不了

题目中的“几乎”并不否定真实高分。一条有效样本能够证明固定身份在某次轨迹上得到这个结果。它不能独自回答平均表现、稳定性、因果收益和隐藏测试迁移，而最终选择往往需要考虑这些问题。

## 先同时摆出所有关键样本

**FACT｜事实：** 以下成绩来自 [最终证据审查](../../project/FINAL_EVIDENCE_REVIEW.md) 和具体运行记录，保留原口径。

| Candidate | quantitative | survival / grade / Level | 证据限制 |
|---|---:|---|---|
| v1 高样本 | 76.04 | 48m / A / L6 | Tier-B 历史摘要，raw 不可得 |
| v1 低样本 | 35.31 | 25m / D / L4 | 与高样本同来源 pair，身份不完整 |
| exact-v6 | 75.29 | 48m / A / L6 | 一个被接受的完整样本；adherence FAIL |
| v8a RUN-0004 | 72.65 | 48m / A / L5 | 同冻结身份的样本一 |
| v8a RUN-0002 | 59.00 | 48m / C / L4 | 同冻结身份的样本二 |

同来源 pair 不表示受控实验；同 Candidate 两局也不表示所有条件一致。完整成绩绑定真实轨迹，比较结论仍需要额外条件。

## Sample size：我们到底观察了多少

**Sample Size（样本量）** 是用于回答某问题的有效观测数量。样本单位必须清楚：两个 Run 是两条轨迹，203 个动作不是 203 个独立 Candidate 性能样本。

**INTERPRETATION｜解释：** 一个长程 Run 内的动作相互影响。早期资源和机会会影响后续，不能把每月记录拆成大量独立样本，再宣称统计证据充足。

对 exact-v6，只有一个完整样本。75.29 是这个样本的分数，不是 expected score（期望分数）。即使这是该候选唯一可用值，也不能把“唯一值”解释成“稳定值”。

对 v8a，两条结果证明至少发生过两种不同结果；仍不足以知道典型表现、低端概率或高分概率。读者可以计算描述性差异，但任何计算都不能创造新的独立观测。

## 为什么 75.29 < 76.04 不证明 v6 更差

“更差”需要定义比较目标。是最大观测值、稳定完成、常见分数、低端风险，还是部署可审查性？不同目标需要不同证据。

**FACT｜事实：** v1 的 76.04 是更高的历史单次记录，但同候选有 35.31 的另一条历史结果，raw 不可得，完整身份不充分。Main 没有把它作为稳定分布或最终包身份。[最终方案审阅](../../project/FINAL_SOLUTION_REVIEW.md)

**INTERPRETATION｜解释：** 若目标只是列“已有记录里的最大数字”，76.04 确实应显示在前面；若目标是选一份可冻结的成熟工程方案，则还要考虑身份、架构与证据完整性。两种问题不应该用同一张排行榜替代。

同样，不能反向把 v1 的低分当成“v6 一定更稳定”。v6 没有重复完整样本，稳定性仍未知。

## 为什么 72.65 > 59.00 不证明代码变差

**FACT｜事实：** v8a 两个样本保持同一冻结行为身份。样本一和二的轨迹、等级和输出格式有差异，但不是两份不同 Candidate。[样本一](../../project/runs/v8a-full-horizon-sample1.md) · [样本二](../../project/runs/v8a-full-horizon-sample2.md)

**INTERPRETATION｜解释：** 模型每次执行可以产生不同文本与决策，环境机会也会不同。因此“输出格式变了”不一定有对应文件修改；“分数下降”不一定是回归代码。

研究应先检查版本与加载身份是否真的相同，再检查轨迹和执行差异。身份相同减少了一个解释，却没有自动证明剩余差异全部来自某一种随机源。

## Selection bias：试得越多，最高值越容易误导

**Selection Bias（选择偏差）** 在反复试分中尤其常见。如果每次只保留最好结果，最后的最大值同时反映方案能力和尝试机会。试过更多次的路线有更多机会遇到高结果。

**TEACHING EXAMPLE｜教学示例：** 两个团队都使用同一方案，一个展示全部两次结果，另一个从许多尝试中只展示最好一次。即使第二个公开分数更高，也不能据此说它采用了更强方案。这里没有给项目增添未记录的尝试次数。

报告所有授权样本、保留低分与技术失败，可以让审查者看到选择过程。它仍不能消除全部混杂，但能减少信息被挑选的程度。

## Technical contamination：成绩之外还有执行过程

**Technical Contamination（技术污染）** 指运行故障、身份错配或协议偏离影响了比较意义。它和自然轨迹差异需要分别说明。

**FACT｜事实：** v7i 历史故障产生 stale score（过期分数）归因风险；v7m 在 M20 技术退出，没有终局成绩；v6 有有效分数同时存在协议偏离。这三种情况不能统一标成“策略失败”。[Provider 取证](../../project/reviews/S07-39_PROVIDER_CONNECTIVITY_FORENSICS.md) · [v7m 取证](../../project/reviews/S07-47_V7M_M20_PARTIAL_RUN_FORENSIC_REVIEW.md) · [v6 记录](../../project/runs/v6-run1-validation.md)

有效分数也不自动适合所有比较。若研究某个 recovery（恢复）规则，而运行并未遵循它，就不能用结果证明“该规则提高了分数”。

## 什么叫描述性、方向性、因果性

| 结论类型 | 可以怎样说 | 需要防止什么 |
|---|---|---|
| Descriptive（描述性） | 这次记录为 75.29，完成 48m | 把单次值当期望 |
| Directional（方向性） | 某些窗口提供值得继续核验的机制线索 | 把线索当收益确认 |
| Inconclusive（无法定论） | 当前记录不能区分几个解释 | 为叙事强行选根因 |
| Causal（因果性） | 改动导致收益，需要能排除其他解释 | 仅凭相关性或历史分差下结论 |

**INTERPRETATION｜解释：** 这是教学用语，不是项目新设的统计分级。本项目许多比较属于 small-N（小样本）、historical（历史）与 confounded（混杂）比较，不能包装成严格统计试验。

没有可支持的统计设计和足够数据时，不应使用 statistically significant（统计显著）、stable distribution（稳定分布）或 causally proven（因果已证明）描述结果。

## 生存、晋升与分数不能相互填补

**FACT｜事实：** v8a 两次都完成 48m，但分别到 L5 与 L4；v1 低样本在 25m 终止却为 L4；v6 完成 48m 到 L6。这些字段在 canonical 记录里分别保存。[最终证据审查](../../project/FINAL_EVIDENCE_REVIEW.md)

**INTERPRETATION｜解释：** 完成率描述样本是否达到时程边界，Level 描述终局等级，分数描述特定评分口径。不能因为都存活就说表现相同，也不能因为等级相同就推断相同分数。

工程决策可能同时关心高位表现和低端风险，但必须明确这些是选择考虑。一个小样本组合不足以给各风险赋可靠概率，不能制造“综合期望效用最佳”的新事实。

## 为什么不能从少数样本补出概率

**TEACHING EXAMPLE｜教学示例：** “两个 Run 都完成”可描述为“这两个已观察 Run 完成”；写成“未来完成概率 100%”则把观察频数当成未知环境的真实概率。这里的两个 Run 不代表完整可能轨迹。

在项目里，v8a 的两次完成保留为样本事实，没有给出总体稳定分布。exact-v6 的一次完整更不能排除自然低端结果，也不能排除技术失败。

**INTERPRETATION｜解释：** small-N 不意味着不能做任何判断。它意味着选择时要使用更窄的语言：固定身份、已观察上界、已知限制和未知重复性。决策可以明确，证据不能被写大。

## 能不能只拿“相似月份”来比较

相同月份、Level 或 Review 结果会减少某些差异，但它们未必有相同 tenure、资源、可选机会和历史负担。长程系统还保留前序选择的影响。

**FACT｜事实：** 策略挖掘发现相近窗口仍有多种混杂，收紧匹配又会使本已很小的样本减少；报告没有因此声明 matched causal gain（匹配因果收益）。[策略挖掘](../../project/research/S10-21_REVIEW_WINDOW_STRATEGY_MINING.md)

**INTERPRETATION｜解释：** 描述性对照可以帮助提出机制假设，不能因表格行看起来相似，就称为严格控制。保留相似与不同条件，比强迫结论明确更可靠。

## 报告分数时的实用纪律

同时显示 Candidate 身份、样本数、完整/部分状态、quantitative 与 partial 字段、survival 月数、adherence 和来源级别。低分样本放在同一视野里，unknown 不填零。

**TEACHING EXAMPLE｜教学示例：** 将“v6 得分 75.29，策略最佳”改写为“exact-v6 一个完整样本为 75.29，运行遵循失败；Main 在成熟三 Skill 路线中选择其历史身份，稳定性与最优性未证明”。后一句更长，但复核者能知道它实际支持什么。

这一纪律不是拒绝决策。工程必须在有限证据下做选择；第 11 章会解释怎样选择，同时保持未知。
