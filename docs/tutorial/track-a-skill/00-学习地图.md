# Track A｜Skill-first 学习地图

这条 Track（学习路线）回答一个问题：在 CareerSim 中，一个 Agent（智能体）怎样使用 Instruction（运行指令）和 Skill（技能模块），把一次公开观察变成有依据的动作，并持续到长程任务结束？主线是最终比赛包对应的 exact-v6 历史配置，不是当前检出的 v8a。你不需要先会 Python，也不需要先运行游戏。

**FACT｜事实**：[exact-v6 来源](../../skill-evolution/04-v6-auditable-control-loop/SOURCE.md)绑定 `candidate-v6-auditable-control-loop` 与三个模块：structured-state-board、rolling-planning、risk-review。它的一局观测为 `75.29 / 52.70 / 48m / A / L6`，同时是 `RUNTIME_ADHERENCE_FAIL`。这使它适合学习“规则怎样写”和“执行怎样失败”，不能把它当稳定高分配方。

- **Core（核心主线）：**01 → 03 → 04 → 05 → 06，共五篇。先读事实层，再读候选排序和风险门；不要求先背条款。

## 学完后应该能够回答

1. Agent、Instruction、Skill 分别是什么，语言模型为何只是 Agent 的一部分？
2. Skill 是代码函数吗？本项目三个 Skill 会自己调用动作工具吗？
3. 为什么不是一个超长 Instruction 就够了？哪些细节应放回模块？
4. 为什么把事实、规划和候选风险拆开？
5. Board / Planning / Risk 谁拥有哪类判断，谁不能顺便接管别人的状态？
6. 一个动作从 observe 到 take_action 怎样产生？它何时成为候选，何时允许提交？
7. CTRL（控制标记）记录什么，为什么它不是动作，也不证明内部判断正确？
8. action 后为什么必须 fresh observe（新鲜观察）？成功回执还缺什么？
9. Adherence（运行遵循）失败与没跑完、低分有什么区别？
10. 为什么 Skill 写得对，不等于 Agent 一定执行得对？

## 怎样使用事实、解释与示例

每章使用三种显式标记。**FACT** 是历史原文或权威记录支持的事实；**INTERPRETATION｜解释** 是帮助理解机制的分析；**TEACHING EXAMPLE｜教学示例** 是构造的场景，都会标明“教学示例，不是历史 Run 原始记录”。UNKNOWN（未知）保留没有足够证据的字段。你可以跟着示例学方法，但不能把示例中的月份、数字或菜单当成真实事件答案。

Evidence（证据）说明某项主张靠什么成立；Provenance（来源链）说明这份内容属于哪个版本、哪次运行。阅读真实案例时先问“Agent 当时能看到什么”，再问“后来审计知道什么”。隐藏字段违规可以作为事后审计发现，不能作为当时正确选项的依据。

原件优先级为：exact-v6 [Instruction](../../skill-evolution/04-v6-auditable-control-loop/instruction.md)与三个历史 SKILL.md、SOURCE → [运行验证](../../project/runs/v6-run1-validation.md)和最终审阅 → [v6 GUIDE](../../skill-evolution/04-v6-auditable-control-loop/GUIDE.md) → 本教程。GUIDE 帮助理解一个版本，本教程训练逐条应用机制；遇到冲突回原件查证。

## 一个入门练习

**TEACHING EXAMPLE｜教学示例，不是历史 Run 原始记录。** 当前公开健康持续下降，下一次绩效反馈窗口临近。某候选能推进工作成果，但公开说明会增加已存在的健康负荷。

先不要选答案。分别写三句话：Board 能确认哪些事实；Planning 当前目标和约束是什么；Risk 应审哪一个候选。若你的 Board 已经写“必须选恢复”，它越过了事实层；若你的 Risk 写“未来每季都选恢复”，它接管了长期策略。

**INTERPRETATION**：正确的入门能力是拆开问题，而不是记住一个菜单动作。请保留候选结果、隐藏阈值与未来晋升为未知。

## 学习边界与完成标准

本路线解释 Tool（工具）、Action（动作）、Observation（观察）的概念与规则，不展开安装、接口注册、服务进程、运行脚本或本机环境。这些属于[Track B｜System / Runtime](../track-b-system-runtime/00-学习地图.md)。仓库与本地资产查[Track C](../track-c-repository-tooling/00-学习地图.md)；样本、取证与选择依据查[Track D](../track-d-project-method/00-学习地图.md)。Track A 集中训练一次决策的职责分工，不独立维护最终工件身份表。

完成标准不是能背出字段。你应能在一个新鲜公开情境中指出事实来源，维护一个可调整目标，给候选做恰当风险审查，再解释为什么必须观察结果；遇到缺失证据时，也能说出不能结论化的部分。章节末尾都有练习与参考分析；先自行作答，再对照。分数预测、稳定最优或实际比赛上传均不属于本路线已经证明的能力。
