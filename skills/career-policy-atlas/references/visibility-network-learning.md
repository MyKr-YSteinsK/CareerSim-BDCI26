# 学习 / 人脉 / 成果可见度

WHEN
- 无更高优先约束的成长、学习、沟通、普通 Story，或 late horizon 的机会价值比较。

OBJECTIVE
- 积累当前仍有响应的多维资本，让真实成果可见；机会价值须有剩余时间兑现。

PREFER
- 把学习/关系/展示与当前公开成果或未来可见机会相连；一个维度局部平时检查其它维度独立价值。
- 学习与 shipping 冲突时先检查真实 deadline/剩余 horizon；普通低风险菜单把所有合法选项一次比较。
- 有完成对象与外部具体认可才是强结果；generic praise、汇报标签、promise/progress 不自动验证交付。

AVOID
- Output-only、最低数值补齐、只堆 Skill、无事实包装汇报、为了关系泄密；late horizon 投资无法兑现长资产。

LOOKAHEAD
- 即时公开回应是什么？到下一可见 checkpoint 能形成什么可用能力/关系/成果？未知收益保留 UNKNOWN。

EXCEPTIONS
- 已验证成果不靠重复汇报再升级；材料/沟通若有新的独立 recognition 对象可比较。普通成本不是 guard。

EVIDENCE
- MEDIUM：竞争轨迹的广义资本与低参考单一路径对照；动作与机会曝光混杂，不能保证某 family 优于另一个。
