# Ownership / 交付与依赖

WHEN
- Main 项目、活跃承诺/blocker，或窗口内交付与长期资产冲突。

OBJECTIVE
- 可承载的真实 ownership 与可确认成果；避免积累无法兑现的承诺。

PREFER
- 比较所有选项的 owner、依赖、质量/合规、负荷与公开 deadline；近期已有承诺可完成/验证时优先兑现。
- 条件满足时偏向关键项目/责任与广义成长；blocked/stale 时比较修依赖、缩范围、真实结果展示或其它合法路线。
- 同等安全质量下选窗口内可完成/验收路径；长资产能及时兑现才参加同场比较。

AVOID
- 关键项目默认答案、按技术路线标题选项、过度承诺、自研必失败/短方案必安全、用 Main 跨月数值归因净收益。

LOOKAHEAD
- 下一公开检查点可完成什么？哪个依赖可能阻止验收？与成果对象相连的认可是否可获得，仍未知什么？

EXCEPTIONS
- 短路径有 material safety/quality/compliance 代价先 guard；正常交付已及时，额外提前收益很小时可比较学习/长期价值。

EVIDENCE
- MEDIUM：同公开菜单分叉有如期交付/延期对照，但状态/时间混杂；延期仍可能晋升，项目高频不证明最优。
