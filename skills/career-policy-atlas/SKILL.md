# Career Policy Atlas｜语义路由

接收 fresh DECISION_CAPSULE 和完整合法菜单。卡片是局部软程序，core 目标与 guard 生存约束优先。只按公开功能情景选择，不按事件名称、ID、历史月份或答案检索。

| 当前首要决策问题 | 读取的 reference |
|---|---|
| 急性身体/心理/安全约束与工作安排 | references/health-survival.md |
| 信任、公开责任、保密、合规或可靠性事故 | references/trust-compliance-conflict.md |
| 资源不可负担或 Energy 本步分配/局部响应 | references/energy-resource.md |
| 临近公开 Review 的窗口目标；正式 Review/promotion/no-advance 后；剩余 horizon | references/review-promotion.md |
| Main ownership、项目依赖、交付/验收与长短资产竞争 | references/project-delivery.md |
| 学习、人脉、成果可见度；其它无重大风险的普通 Story | references/visibility-network-learning.md |

优先处理当前未解除的 material constraint，其次正式窗口变化，再菜单类型/活跃交付，最后普通成长。Energy 成本危机用资源卡；其它急性危险先按对应健康或信任情景。普通风险提示不自动当 material，不按词频判危机。

首次需要路由时读本 SKILL.md；SkillTool 返回 skill_directory 后，以它为根用 read_file 读所选 references 文件。通常每决策最多一张卡；若两个 materially independent 约束确实交叉才允许第二张，注明原因。不要启动时读全部卡，也不要每步重读所有 Skills。已在当前 context 内的同一卡直接使用；缺失/可见压缩后只重读相关卡。读失败不能假装已加载：一次同局重建仍失败则遵守 core 保守公开边界并记录 UNKNOWN，不寻求外部检索服务。

只输出当前卡名与一句路由理由，不输出新 planner、第二人格或长期记忆；不提交动作。旧卡可能仍在模型历史中，路由并不保证宿主删除旧 tool output；每次只把当前 capsule 与相关程序置于决策重心。
