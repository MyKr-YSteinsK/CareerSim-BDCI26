# Risk Review｜重大风险审查

## 职责与触发

只审查当前候选是否忽略了新鲜、明确的公开 `Material Risk`，以及当前合法选项中是否有直接相关的缓解措施。它是罕见的风险门槛，不是常驻审查或一般负面信号分类器。

仅在公开证据明确显示以下重大后果时触发：严重 Health 后果、明确的埋雷/危险警告、信任危机、保密/合规风险、报复/升级威胁、解雇/生存威胁，或含义相当的重大后果。只按当前公开文本判断，不猜隐藏计数、阈值或概率。

普通绩效反馈、一般分歧或不满、普通压力/工作量、少量 Health/Dignity 成本、泛化不确定性，或仅仅存在更安全选项，都不单独触发本 Skill。它们由正常决策作为 `Soft Cost` / opportunity cost 考虑；不能单独要求 `RECONSIDER` 或自动否决有明显公开收益的成长路径。若软成本与重大风险并存，完整审查重大风险，不得淡化。

## 输入与输出

只使用当前游戏 session 的 fresh public `observe`、可见反馈、当前合法选项和已掌握的公开 Handbook 规则。不得使用其他局信息、局后结果、隐藏字段或推测出的阈值。

返回一个状态和一句基于证据的理由：

- `ALLOW`：没有被忽略的重大风险；软成本本身不要求改选。
- `WARN`：重大风险公开可见，但没有明确、直接的合法缓解项，或证据不足以要求重比。
- `RECONSIDER`：仅当 fresh public `Material Risk` 明确、存在直接相关的合法缓解项、且当前候选未处理该风险时使用。同一个 Agent 重新比较当前候选与缓解项；不要求选择最保守方案。
- `UNKNOWN`：session、状态、证据或选项不新鲜/不清楚。说明未知并回到正常决策，不猜测或阻断。

只有当前合法选项确实包含 `处理历史埋雷`，且新鲜公开上下文有对应的重大埋雷/信任风险时，才考虑该选项。不得声称其效果已知、一次即可清除风险或应定期选择。

## 权限

- Can Submit Action: No。
- 可建议同一个 Agent 对当前候选与直接相关的合法缓解项进行一次比较；不得创建第二审查者、Agent、Team、Swarm、Memory、Planning 或持久化风险状态。
- 不调用 `observe`、`take_action` 或 `new_game`。唯一提交者仍是 Single Agent。
