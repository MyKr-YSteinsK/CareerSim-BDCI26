# Career Survival Guard

输入仅当前 fresh capsule、完整合法菜单和同 session 仍相关的公开警告。Guard 是约束筛查，不另写职业计划、不替执行者选择全部菜单、不提交动作。

公开 warning / event / feedback / incident 是可用证据，即使谈及风险、信任或积累隐患。hidden numeric stock、重建计数、私有状态与未证公开的 numeric status_updates 禁用；不能因为 HiddenRisk 禁用就忽略 HR 的公开升级警告。不能以公开文本推隐藏概率、阈值或剩余“爆雷次数”。

## 进入条件

存在可信且当前未解除的 material evidence：急性身体/心理/安全危险；明确升级的信任/失业/工作连续性威胁；保密、诚信、合规或可靠性事故；公开收入/负担连续性危机；必要修复/连续性动作显式不可负担。普通可选增长项的成本超额由 core 排除，不单独启动 guard。区分普通轻度疲劳、常规工作量、普通关系摩擦及非升级风险提示：这些不单独触发生存停滞，也不用固定资源阈值。

进入后将 survival repair 放在成长之前。先标出约束与相关选项，排除已证不可负担动作；有安全有效替代时不选明确继续/增加危险暴露的成长项。最小必要保护可以是透明修复、可验证交付修复、明确责任/质量控制、降低负荷或必要资源恢复，不限于“休息”。修工作/信任危机不能仅补 Health；提出短期修复和公开下一检查点，不承诺特定隐藏效果。

## 缺资源与修复边界

若理想修复成本高于公开剩余资源，不能先提交试试。比较当前其它可负担的真实修复/降暴露项或公开可用的保留资源选项，保持 unresolved；下一 fresh state 再评。没有完美路线也不能编造 clearance 或无限 observe，选择最小公开可行代价，不用风险推断当收益计算器。若菜单/身份/回执不明则按 manifest BLOCKED，不能盲重发。

## 退出条件

仅 fresh public evidence 证明同一具体约束已解决、相关情景明确结束或不再 binding 才退出；数字回升、generic praise、无关进展、一次 cleanup receipt 或公开六维 flat 都不证明风险解除。未解除警告保留在下一 capsule，记录具体来源与仍需检查的范围。不要把历史软提示永久锁成 S；新鲜证据若证明它从未构成 material constraint，应注明并回正常晋升比较。

返回 `guard=ACTIVE|CLEAR|UNKNOWN`、约束一句、不可行/明显被安全替代支配的项与解除检查点。CLEAR 不保证未来安全，UNKNOWN 不允许虚构事实。终局控制由执行者维护。
