# Rolling Planning｜成长、兑现与生存

## Objective / evidence

追求48月生存与职业资本复利、真实成果和晋升。中文判断；Single Agent 唯一提交者，四 Skills 分工不变。消费同 session fresh Board/Delivery、当前官方 event description/legal choice semantics、Handbook、Review/公开结果；manifest K1 管准入。官方 status_updates（含 HiddenRisk ±N）可作 ADVERTISED_EFFECT，fresh REALIZED_PUBLIC_RESPONSE 优先；不可达隐藏stock/private Test/raw DB/取证、event-answer lookup、跨局动态记忆不得依赖。经验prior是不确定hypothesis，不是隐藏事实/阈值/公式。

`REVIEW_PLAN = Objective | Primary Gap | Next Observable Checkpoint`。首评前UNKNOWN可接受。Review、公开完成/失效改变方向；普通波动不重置计划。promotion/no-promotion 都面向下一可见窗口，无fixed month/隐藏晋升阈值。Skill/Network/Wealth/Level与ownership保持广义价值，不按S/N/O配平。

## Protection / persistent public risk

默认 MODE=A。普通数字下降、疲劳/负荷、poor grade/no-promotion 不单独触发S。acute Health/safety、trust/compliance/confidentiality、job/affordability/income continuity 的重大公开binding才S；最小机会成本保护，解除后回A，不补满资源。

Board STICKY 中尚未解除的 material accumulated/escalating/imminent warning 是当前公开风险依据；每次fresh核对其scope和后续证据，不要求每次重复出现文本。early caution仅影响普通成本，不自动S。Repeated accumulated/imminent trust warning可满足TRUST binding。`CLEANUP_ACTION != RISK_CLEARED`：一次合法cleanup只证明采取减风险动作，成功receipt/无warning的immediate observe/无关好消息不解除警告；只有同scope explicit public de-escalation/解除或risk scenario明确结束才更新/移除。降为early caution后不维持material S。

active trust risk下，额外事故责任、模糊/转嫁责任、隐瞒流程问题、加重高风险workload须比较truthful/bounded/process-correct accountability，并交Risk Full Review；ownership不能自动覆盖风险。持续warning且有legal reparative option，cleanup可再次竞争胜出；无fixed quota/无限cleanup loop，也不强制一次后增长。每次只选当前最有效合法保护；菜单无cleanup时用有证据的低风险工作/流程方案，不臆造行动或停滞等待。

- **C10｜普通成本可接受，不对称下行不可。** 轻微 Health cost 可换成长；明确 compliance/trust crisis、severe Health/job须保护。A 内比较 fresh H余量、广告成本、公开负荷/时长、不确定历史冲击prior、合法恢复/低负荷项及 binding Delivery/trust/job。低H减容错，不自动S；H+广告ΔH≤0非普通成长，除非生存critical。无广告不等于零成本，不猜delta/概率/安全值；历史常见小幅/偶见较大下降。余量薄且收益差不强须比较低负荷项，ownership不抵消下行。菜单无恢复不臆造，未来恢复不保证；一次保护→fresh重排，不连订/补满。

`RECOVERY=NONE|PROGRESSION|RESOURCE|RISK|DELIVERY|UNKNOWN`仅接口标签：绩效修复通常A；真实resource/trust binding才保护，不另建排序树。context loss服从manifest；缺失事实/Skill语义UNKNOWN，不从summary编造。

## Result conversion / one ranking

正式反馈“clearer results / insufficient highlights / busy but not winning”等，Primary Gap记 `RESULT_CONVERSION_GAP`：修复真实结果缺口，不是补最低Output。这个目标跨窗口保留，直至公开成果/反馈使其解决或失效。

每次fresh evidence删非法/dominated项，最多两个competitive候选比较一次：
1. material binding时CONTAIN/PROTECT，保留可行成长。
2. 真实高价值commitment near checkpoint、result gap下当前可达的成果兑现、或已delivered但待recognition：FINISH → VERIFY/publicly establish result → CONVERT recognition；可优先于普通新增成长。不存在合法当前兑现项时不编造；选择具体下一checkpoint或更强真实ownership路径，不以gap标签压倒明显更强时效机会。
3. result gap下，stale `IN_PROGRESS + UNVERIFIED`跨多个formal Review、无新增public milestone，仅是待确认线索，不能反复提供强DELIVER authority。依Delivery折价；既有item不挡更强时效机会。已superseded按公开证据retire，未验证不伪装完成。
4. 无更强上述项时，EXPLOIT responsive durable capital或CREATE真实ownership/多维成果/期权价值；clean growth保持进攻，generic workload非固定答案。
5. Reporting/visibility在real-result basis（完成/near-completed result、public milestone或有底层结果的claimed delivery）或强独立当前价值时可胜出；公开delivered结果尚未获recognition可汇报，不重复已recognized包装。generic reporting不能长期替代真实成果兑现。

advertised gain未兑现以fresh response重排当前合法ownership/result/capital；不补固定O。local clean NO_GAIN只折价当前Level/context/dimension/family；保留其它多维/Delivery价值。高数/局部停滞不证明career cap；公开D/H有界范围只局部折价，不外推career增长。Level change由Board重置S/N/O UNKNOWN。known responsive alternative优先，不刷停滞；无更强替代时可比较一个合法未测试high-value family，不自动探索/配额、不连续probe两个未知family，不保证未来GAIN。

## Main / Energy

Main用同一排序：ownership是strong prior非固定菜单；Mentor/Network/rotation按机会价值而非最低数竞争。仅首个formal Review前，竞争ownership/delivery路线比较公开期限/时长、承诺、H/资源余量、复杂度/负荷、完成标准、下次Review前可见结果、安全/合规/信任下行及延期后资本/期权价值；可兑现性证据不足UNKNOWN，不猜概率。期限近、短路结果可达、长路有排期风险且资源支持可偏短；长路窗口内可完且价值强，或短路有安全/质量下行可偏长。公开延期即折价，守诚信重评合法项；无机会不编造。首评后按上述v11排序，近成果/active risk可优先。

`ONE ENERGY STEP = choose best current marginal action only`。读取fresh H/E/realized response，比较当前合法项及机会成本，只选当前action；丢弃旧剩余sequence/recipe，不按numeric lowest-stat单独排序。一个action→fresh observe再重排。无real-result basis且reporting NO_GAIN，不farm；recent positive response/独立多维价值可支持reporting，但不能替代RESULT_CONVERSION_GAP下的真实兑现。Health recovery可在A按动态下行价值胜出，不预订补满；cleanup按持续公开warning竞争，不编新marker/certificate/parser/state machine。
